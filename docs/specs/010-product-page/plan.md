## Context

FR-8 and FR-9 need a product page: the category cards already link to `/<category>/<product>`, which 404s today. The approved spec adds the route, a gallery with a zoom dialog, sale price with % off, a pre-order status, a quantity selector, disabled cart/build buttons, warranty, what's in the box and the existing `SpecTable`. Two schema changes (`preorderShipsOn`, `boxContents`) ship in one migration with seed data.

## Schema and seed

- `preorderShipsOn DateTime? @db.Date` and `boxContents String[] @default([])` on `Product`; `pnpm db:migrate --name product_page_fields`, then `pnpm db:seed --reset` on dev.
- Seed: `boxContents: z.array(text()).optional()`, `preorderShipsOn: z.iso.date().optional()`. `productData()` writes `boxContents: part.boxContents ?? []` and `preorderShipsOn: part.preorderShipsOn ? new Date(part.preorderShipsOn) : null` (a `"YYYY-MM-DD"` string parses as UTC midnight, which `@db.Date` stores as that day). `boxContents` joins `CATALOG_FIELDS`; `preorderShipsOn` stays create-only.
- Data: box contents for all CPUs, GPUs and PSUs and a few others, from the `sourceUrl` pages; pre-orders 265K (`"2027-02-01"`) and RTX 5060 Ti (`"2027-01-15"`).

## Status logic (`lib/stock.ts`)

- `StockStatus` adds `"pre-order"`, label "Pre-order".
- `getStockStatus(product: { stock; lowStockAt; preorderShipsOn: string | null }, today: string)`: stock ≤ 0 → out-of-stock; `preorderShipsOn > today` (string compare) → pre-order; then the current low/in-stock rule.
- `manilaToday(now = new Date())`: `Intl.DateTimeFormat("en-CA", { timeZone: "Asia/Manila" }).format(now)` → `"YYYY-MM-DD"`.
- `clampQuantity(value: number, max: number)`: `NaN`/non-finite → 1, truncate, then clamp to `[1, max]` (max ≥ 1 is assumed; out of stock disables the selector).
- `toDateString(date: Date | null)` in `lib/products.ts` turns the Prisma `Date` into `"YYYY-MM-DD"` (`toISOString().slice(0, 10)`), so card and page data stay plain.

## Formatting (`lib/format.ts`)

- `discountPercent(price, salePrice)`: `Math.floor((price - salePrice) * 100 / price)`, multiplying before dividing so integer cases like exactly 50 % don't lose to float error.
- `formatWarranty(months)`: 0 → "No manufacturer warranty"; `months % 12 === 0` → "`n`-year warranty"; else "`n`-month warranty".
- `formatDate(isoDate)`: `Intl.DateTimeFormat("en-PH", { dateStyle: "long", timeZone: "UTC" })` on `new Date(isoDate)`.

## Data (`lib/products.ts`)

- `productCardSelect` + `preorderShipsOn`; `ProductCardData.preorderShipsOn: string | null`.
- `getProductPage = cache(async (slug) => db.product.findFirst({ where: { slug, status: "ACTIVE" }, select: {...} }))` with React `cache`, returning plain data (dates as strings, images ordered by `sortOrder`), or `null`.

## Route (`app/(store)/[category]/[product]/page.tsx`)

- `generateMetadata`: `getProductPage(slug)`; `null` → `notFound()`; title = name; description = `truncateDescription(description, 155)` (word boundary + "…", a small local helper) or the generated sentence; `alternates.canonical` = `productHref`.
- Page: `await connection()`; lookup; `null` → `notFound()`; `category !== product.category.slug` → `permanentRedirect(productHref(...))`; `today = manilaToday()`; status; specs via `isBuilderCategory` + `validateSpecs` (on failure `console.error` with the slug and issues, then the "not available" line).
- Layout per the spec: breadcrumbs; `lg:grid-cols-2` with gallery left and the buy box right (brand, `h1`, `ProductPrice`, status line with icon, `QuantitySelector`, disabled buttons with `aria-describedby` to the "coming soon" line, warranty with `ShieldCheckIcon`); below: Overview, Specifications (`h2` + `SpecTable`), What's in the box (`ul`).

## Components

- **`ProductGallery`** (`"use client"`): props `images`, `productName`. State `index`. Main image inside a `button` "Enlarge image" with `ZoomInIcon`, wired as the `DialogTrigger` (Base UI `render` prop). Thumbnails: `ul` of buttons with `aria-label="Show image n of total"`, `aria-pressed`. Dialog content: large `ProductImage` with `loading="eager"`, `DialogTitle` = current alt (visually hidden), Previous/Next buttons and `onKeyDown` for ArrowLeft/ArrowRight (wrapping). Base UI returns focus to the trigger on close. No images → plain `ProductImage` fallback.
- **`QuantitySelector`** (`"use client"`): props `max`, `disabled`. Holds the input text while typing; `clampQuantity` on blur and on the buttons; `Field`/`Label` for the "Quantity" label.
- **`ProductPrice`** (server-compatible): sale and no-sale variants; `<span className="sr-only">Was</span>` before the struck price; badge only when `discountPercent > 0`.
- **`ProductCard`**: new `today` prop → `getStockStatus(product, today)`; `ListingResults` takes and forwards `today`; the category page passes `manilaToday()`.
